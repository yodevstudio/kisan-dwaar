# Kisan Dwaar — Rajasthan Innovation Challenge Submission

**Challenge:** Revamp of Department of Agriculture Web Portal — Citizen-Centric Digital Front-End

**Submitted by:** YoDevStudio, Jodhpur, Rajasthan

Kisan Dwaar is a proposal prototype built for the Rajasthan Innovation Challenge. It is not an official Rajasthan Government deployment and does not process real citizen application data.
